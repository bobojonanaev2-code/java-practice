## Уточнения задания и представление данных

Реализация C++17 поддерживает любое положительное число переменных
`x1, x2, ...`. `Monomial` содержит закрытые поля: точный рациональный
коэффициент и `std::vector<int>` неотрицательных степеней. Например,
`Monomial(3, {2, 1})` означает `3*x1^2*x2`.

`Polynomial` хранит число переменных и упорядоченный набор одночленов
в `std::map`: ключ — вектор степеней, значение — коэффициент. Это
каноническое представление списка: каждый набор степеней встречается
не более одного раза, нулевые коэффициенты отсутствуют. Метод
`monomials()` возвращает список как `std::vector<Monomial>`.
Все члены, включая введённые нулевые, проверяются на согласованность
числа переменных. Константа имеет нулевые степени всех переменных.
Нулевой многочлен хранит пустой набор членов, но сохраняет число переменных.

Приведение подобных выполняется сразу при создании и после операций:
коэффициенты при равных степенях складываются, нулевой результат удаляется.
Поэтому отдельная команда приведения подтверждает уже приведённый вид.
Принадлежность означает наличие члена **с тем же коэффициентом и степенями
после приведения**: в `3*x1 - 2*x1` есть `1*x1`, но нет `3*x1` и нет нулевого члена.
Равенство не зависит от порядка ввода, однако требует одинакового числа
переменных. При равенстве разных размерностей возвращается `false`,
арифметика разных размерностей отклоняется с понятной ошибкой.

Арифметика возвращает новые объекты, исходные многочлены не меняются.
Сумма и разность объединяют коэффициенты по ключам. Произведение перебирает
пары членов: коэффициенты перемножаются, степени складываются.
При `m` и `n` членах произведение требует `m*n` парных операций плюс поиск
ключей в упорядоченной карте. Переполнение степени `int` проверяется до сложения.

## Точные рациональные коэффициенты и ограничения

Числитель и знаменатель — `int64_t`. Поддерживаемый диапазон входных целых:
**от −9223372036854775807 до 9223372036854775807**. Значение `INT64_MIN`
сознательно исключено, чтобы отрицание и модуль были безопасны. Знаменатель
не равен нулю, знак переносится в числитель; дробь сокращается по НОД.
Ноль всегда представлен как `0/1`. Отрицательный знаменатель допустим во вводе.

При умножении выполняется перекрёстное сокращение до перемножения;
при сложении используется НОД знаменателей. Каждое сложение и умножение
целых проверяется **до** вычисления. Если промежуточный результат не помещается
в указанный диапазон, операция выдаёт ошибку. Это ограничение относится и
к промежуточным результатам: некоторые выражения с представимым окончательным
ответом могут отклоняться. Произвольная точность и приближение через `double`
не используются. При переполнении равенство деления не подменяется приближённым
результатом — вычисление прерывается с сообщением.

## Деление: порядок, инвариант и завершение

Выбран **лексикографический порядок**: сначала сравниваются степени `x1`,
при равенстве — `x2`, затем следующие переменные. Например,
`x1^2 > x1*x2^100 > x2^1000`. В карте старший член стоит первым.
Это не порядок по суммарной степени.

Делим `P` на один ненулевой `D`. Изначально `Q = 0`, `R = 0`, `H = P`.

1. Берём старшие одночлены `H` и `D`.
2. Если каждая степень старшего члена `H` не меньше соответствующей степени
   старшего члена `D`, делим коэффициенты точно, вычитаем степени и получаем
   одночлен `t`. Заменяем `Q` на `Q+t`, а `H` на `H−D*t`.
3. Иначе переносим старший одночлен `H` в `R`, удаляя его из `H`,
   **и продолжаем обработку остальных членов**.
4. Завершаем, когда `H = 0`.

**Инвариант цикла: `P = D*Q + R + H`.** Он верен при инициализации.
В первом случае прибавление `D*t` к произведению компенсируется вычитанием
из `H`. Во втором один и тот же член прибавляется к `R` и вычитается из `H`.
Следовательно, в конце **`P = D*Q + R`**. Ни один член остатка не делится на
старший член `D`. Демонстрация дополнительно проверяет полученное равенство.

На каждом шаге старший вектор степеней `H` строго уменьшается: он либо
удаляется, либо сокращается, а все новые члены ниже него в лексикографическом
порядке, совместимом с умножением. Для фиксированного конечного числа
переменных лексикографический порядок на неотрицательных целых векторах
не допускает бесконечной строго убывающей последовательности: первая
координата может уменьшиться лишь конечное число раз, после её стабилизации
применяется тот же аргумент к остальным координатам. Поэтому цикл завершается
(либо раньше сообщает о выходе за поддерживаемый числовой диапазон).

В нескольких переменных ответ зависит от порядка переменных; требование
«суммарная степень остатка меньше степени делителя» здесь не применяется.
Например, `(x1+x2)/x2` даёт частное `1` и остаток `x1`.

## Запуск и меню

Откройте `../CppPractice.sln`, выберите **task-16-8 → Назначить запускаемым
проектом**, затем **Debug | x64 → Ctrl+Shift+B → Ctrl+F5**.
Понадобятся MSVC и Windows SDK из рабочей нагрузки C++.
Параметры `--test` и `--demo`, команды сборки и фактический статус проверки
приведены в [главном README](../README.md).

Изначально загружен контрольный пример. Команды меню:

| Номер | Действие |
| --- | --- |
| 1, 2 | Ввести соответственно `P` или `Q`. |
| 3, 4 | Показать многочлены; привести подобные и показать результат. |
| 5 | Выбрать `P` или `Q`, затем ввести проверяемый одночлен. |
| 6 | Проверить равенство `P` и `Q`. |
| 7, 8, 9 | Получить `P+Q`, `P−Q`, `P*Q`. |
| 10 | Получить частное и остаток `P/Q` и проверить равенство. |
| 0 | Завершить программу. |

Ввод многочлена: число переменных, число одночленов, затем каждый одночлен
в отдельной строке `коэффициент e1 e2 ...`. В меню разрешены 1..100 переменных
и 0..10000 одночленов для защиты от случайного чрезмерного выделения памяти;
классы не ограничены этими учебными пределами. Степени — от 0 до `INT_MAX`.
Введённое число членов 0 задаёт нулевой многочлен.

Ошибка формата, лишние данные, отрицательная степень, нулевой знаменатель,
несовместимая размерность или деление на ноль дают сообщение и возвращают
в меню. Неверный ввод нового многочлена не заменяет сохранённый объект.
Конец ввода в любом месте завершает программу: в Windows — `Ctrl+Z`, Enter;
при перенаправлении — конец файла.

Весь следующий блок можно последовательно ввести в меню. Он задаёт

```text

```

Ожидаемые значимые строки (подсказки меню опущены):

```text
P = 1*x1^2 + 1*x2 + 2
Q = 1*x1 + 1
Частное P / Q = 1*x1 - 1
Остаток = 1*x2 + 3
P = Q * частное + остаток: true
```

Вывод всегда явно показывает коэффициент `1`; это оформление записи,
а не изменение значения. Другие ожидаемые результаты контрольного примера:

```text
P + Q = 1*x1^2 + 1*x1 + 1*x2 + 3
P - Q = 1*x1^2 - 1*x1 + 1*x2 + 1
P * Q = 1*x1^3 + 1*x1^2 + 1*x1*x2 + 2*x1 + 1*x2 + 2
```
